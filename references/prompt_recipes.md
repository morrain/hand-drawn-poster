# 场景化 精细 Prompt 实战配方集 (Hand-Drawn Poster Detailed Prompt Recipes)

本文档提供包含**全量显式文案、丰富手绘视觉组件与小智 IP 强联动**的高信息密度生图 Prompt 实战配方。

每个配方均提供**双语版本**：
- **🔵 中文确认版**：供用户审核所有画面文案与构图内容是否符合要求。
- **🟢 英文生图版**：用于实际调用生图模型，以获得最佳图像质量。
