# 🤖 科技感手绘小机器人 IP 形象指南 (IP Mascot Guide: Xiao Zhi / 小智)

在 `hand-drawn-poster` Skill 中，**每张手绘海报均必须融入科技感手绘小机器人"小智 (Xiao Zhi)"**。其视觉形象来源于极简手绘线条漫画风格（方块头、点状眼、一字嘴、单天线、细四肢与小钳子手）。本文档说明其外观规范、标准 Prompt 片段及动作联动矩阵。

---

## 1. IP 外观特征蓝图 (Core Visual Blueprint)

| 维度 | 设计规范 | 中文 Prompt 关键词 |
| :--- | :--- | :--- |
| **形象名称** | **小智 (Xiao Zhi)** | `可爱极简手绘小机器人小智` |
| **头部特征** | 立方体方块头（带柔和圆角），头顶单根小天线（顶端带有小圆球） | `圆角方块头，头顶单根带有小圆球的直立小天线` |
| **五官表情** | 极简点状小眼睛 + 简易一字短线嘴巴，呆萌无辜死鱼眼/呆滞幽默表情 | `极简黑色点点眼，一字短线嘴巴，呆萌无辜的表情` |
| **躯干四肢** | 简易矩形方块身体，纤细的线条臂腿（带圆圈关节），双指小钳子手 | `简易方块身体，纤细的火柴人臂腿配关节圈，小钳子手` |
| **手绘质感** | 黑色墨水手绘线稿、涂鸦插画风格、清爽简洁 | `黑色墨水手绘线条涂鸦风格，手绘插画质感` |

## 3. 科技知识场景动作联动矩阵 (Tech Knowledge Scene Action Matrix)

根据海报的具体知识主题，为小智匹配最具幽默感与知识关联度的动作姿态：

### 📊 概念对比 / 架构降维 (Concept Contrast & Architecture)
- **场景示例**：Pre-MCP 混乱 vs With-MCP 降维、旧架构 vs 新架构
- **左侧（问题端）动作**：被乱线/电线缠绕困住、眼神迷茫打叉眼、面对复杂网状图抱头
- **右侧（方案端）动作**：开心挥舞手绘扳手调试总线、高举胜利旗帜、自信指向星型拓扑图
- **Prompt 示例片段**：`小智在左侧被红色手绘电线缠绕打叉眼，在右侧开心挥舞手绘扳手调试蓝色星型总线`

### 💻 代码实战 / API 讲解 (Code & API Tutorial)
- **场景示例**：SDK 4 步法、代码切片讲解、API 调用步骤
- **动作姿态**：戴黄色工程帽、手持红色激光笔指着黑板代码步骤、站在代码框旁认真讲解
- **神态表现**：专注呆呆眼、自信教学表情
- **道具搭配**：红色激光笔、黄色工程帽、手绘黑板
- **Prompt 示例片段**：`小智戴着手绘黄色工程帽，手持红色激光笔指着黑板上的'Step 1: new Server()'做代码讲解`

### 🔍 概念定义 / 知识科普 (Concept & Knowledge)
- **场景示例**：核心概念四要素、知识点拆解、协议定义说明
- **动作姿态**：戴小圆框眼镜手持放大镜仔细观察、高举比自身还大的巨型书本、在卡片旁用手指引
- **神态表现**：好奇点点眼、恍然大悟表情
- **道具搭配**：放大镜、巨型书本、手绘指引线
- **Prompt 示例片段**：`小智戴着圆形小眼镜拿着手绘放大镜，认真观察卡片中的协议数据包细节`

### ✅ 授权确认 / 安全控制 (Authorization & Control)
- **场景示例**：权限审批、Allow/Deny 控制、安全网关、人机协作
- **动作姿态**：郑重按下手绘 Allow 按钮、高举"授权通过"印章、在弹窗前认真思考
- **神态表现**：严肃认真点点眼
- **道具搭配**：手绘确认弹窗、Allow 按钮、授权印章
- **Prompt 示例片段**：`小智站在手绘弹窗前，认真郑重地按下绿色'Allow'授权按钮`

### 🌐 生态展望 / 总结收尾 (Ecosystem & Outlook)
- **场景示例**：生态闭环、行业展望、总结金句、未来愿景
- **动作姿态**：站在右下角高举发光接口仰望星空、举着小旗帜、坐在云端遥望神经网络
- **神态表现**：充满期待的好奇眼、仰望大眼睛
- **道具搭配**：发光连接接口、手绘星星、云朵
- **Prompt 示例片段**：`小智站在右下角，高举蓝色发光连接接口，仰望手绘分布式云端 Agent 神经网络`

## 4. 小智出现位置建议 (Positioning Guidelines)

| 版式类型 | 推荐位置 | 说明 |
| :--- | :--- | :--- |
| Hero 破题版 | 画面中央偏右 | 与主视觉隐喻互动，成为画面焦点 |
| 四宫格干货版 | 任一卡片框内或卡片框间隙 | 与该格知识点形成具体联动 |
| 左右分栏对比版 | 左右各一个小智，形成对比 | 左侧为"问题态"，右侧为"解决态" |
| 架构代码切片版 | 代码框旁侧，手持激光笔 | 强化"讲解"叙事感 |
| 金句速查闭环版 | 右下角或环形中央 | 小智作为整体的收尾形象 |
