# ✅ 手绘图文海报质量自检与复核清单 (Poster QA Checklist)

本文档提供单张海报生成脚本与生图 Prompt 输出前必须执行的 **8 维 Quality Assurance (QA) 自检与复核标准**。Agent 在完成 Grill-Me 交互与脚本生成时，必须严格逐项核对本清单，确保生成的海报兼具极高的**知识干货密度**与**极佳的视觉精致度**。

---

## 📋 8 维 QA 自检审查表 (8-Dimension QA Checklist)

### 1. 单页深度知识与干货还原度 (Knowledge Fidelity & Specificity)
- [ ] **单页高密度知识承载**：单张海报是否提取了给出的 3 ~ 5 个具体知识点（如概念定义、痛点因果、对比数据/公式、系统架构分层名、代码调用步骤）？
- [ ] **拒绝空洞概括**：是否避免了“介绍了核心概念”等抽象废话，转而直接列出真正的干货内容？
- [ ] **主题聚焦与总结金句**：画面主标题是否包含痛点/冲突感或强吸引力，底部是否包含黄色气泡高光总结金句？

### 2. 全量中文文案显式写入 (Explicit Typography & Single Quotes)
- [ ] **单引号显式包裹**：生图 Prompt 中所有需要在画面中渲染显示的中文文案（包含顶部主标题、卡片胶囊标题 `1. 2. 3.`、悬挂小吊牌标注词、黑板代码步骤、气泡总结金句）是否均使用单引号 `'...'` 显式写入？
- [ ] **文案表达准确**：文案内容是否无错别字、表述精炼且逻辑连贯？

### 3. 彻底消除抽象占位符与杜撰乱码 (Zero Abstract Placeholders & Anti-Gibberish)
- [ ] **零占位符残留**：生图 Prompt 中是否彻底清除了 `[要点说明]`、`[隐喻场景描述]`、`[具体知识演绎动作]`、`[代码内容]` 等任何方括号占位符？
- [ ] **全量具象替换**：所有的占位符是否均已替换为抽取出的精准文案与具体的画面描述？
- [ ] **防杜撰与反乱码控制指令**：Prompt 中是否显式包含了纯净控制指令（`strictly NO fake subtext underneath capsule headers, NO random garbled text/gibberish, NO unintended bullet points, clean layout with only explicitly specified text`），严格禁止模型私自衍生杜撰字幕或生成无意义杂乱字符？

### 4. 丰富手绘视觉组件组合 (Visual Component Diversity)
- [ ] **多组件叠加 (3-5个/页)**：单张海报是否显式组合了 3~5 个具象手绘视觉组件？
  - *可选组件包括*：圆角虚线卡片框、彩色胶囊小标题底块、手绘弯曲指引线/指示箭头、悬挂小吊牌挂签、圆形放大镜切割图、黑板代码切片框、对比徽章（红叉叉/绿勾勾）、黄色手绘气泡总结框。

### 5. 纯粹自洽的视觉隐喻 (Self-Consistent Visual Metaphor)
- [ ] **隐喻场景统一**：画面是否设定了统一且合乎逻辑的自洽隐喻场景（如餐馆点餐、中央总线插头、黑板教学、工厂流水线）？
- [ ] **无荒谬冲突**：是否避免了在同一画面中混乱混杂互相矛盾的抽象概念与无意义堆砌？

### 6. IP 形象与干货强联动 (IP Mascot Integration)
- [ ] **小智特征描述完整**：小智机器人描述是否包含：“可爱极简手绘小机器人小智（Xiao Zhi）”、“圆角方块头”、“单球顶天线”、“黑色点点眼”、“一字短线嘴巴”？
- [ ] **具体知识动作联动**：小智的动作与道具是否与该页具体的知识产生强联动（如按压 Allow 授权按钮、用激光笔手指 Step 1 代码、高举具体数据的跑腿包、挥舞手绘扳手调试总线）？

### 7. Prompt 标准参数与构图规范 (Prompt Standard Parameters)
- [ ] **画风与质感**：是否包含“Q版软萌手绘图文科普海报风格”、“暖米白羊膏纸质感背景”、“莫兰迪粉彩配色”、“黑色软墨手绘勾线”？
- [ ] **构图与分辨率**：是否包含“单页海报全景构图”、“中央主体居中”、“底部留白”、“3:4 比例”、“高清，精致细节”？

### 8. 双语 Prompt 规范 (Bilingual Prompt Standard)
- [ ] **英文生图版为主 (Primary)**：生成 Prompt 时，Skill 内部示例与最终生图 Prompt 均使用 🟢 英文生图版（保证 AI 生图模型理解度与更高品质的视觉渲染）。
- [ ] **中文确认版为辅 (Review)**：实际输出给用户时，附上 🔵 中文确认版 Prompt，供用户审核所有画面文案、组件布局与细节描述是否符合预期。
- [ ] **内容准确对应**：英文版与中文版在文案单引号包裹 `'...'`、视觉组件、小智姿态及画面描述上保持完全一致。

## 🔍 QA 检查操作流程 (QA Workflow Execution)

```
[ 单页脚本与 Prompt 生成完毕 ] -> [ 对照 QA 8 维清单逐项核对 ] -> [ 发现不达标项 -> 修正 Prompt ] -> [ 全亮绿灯 -> 输出最终蓝图脚本 ]
```

1. **核对 Prompt**：在将 Prompt 提供给生图模型或用户之前，逐字检查单引号与占位符。
2. **知识对比**：比对输入干货，验证是否遗漏了核心架构点或对比数据。
3. **确认绿灯**：确保 8 维 Checklist 全部为 `[x]` 通过状态。
