# 手绘视觉风格指南 (Hand-Drawn Style Guide)

本文档为 `hand-drawn-poster` Skill 的核心视觉风格标准参考。本 Skill **统一使用 Q 版软萌图文科普风格 (Cute Q-Style Educational Infographic)**，所有海报须严格遵循以下规范。

---

## 🌟 Q 版软萌图文科普风格规范 (Cute Q-Style Educational Infographic Standard)

### 1. 整体画风基调

- **风格关键词**：Q 版软萌 / 手绘涂鸦 / 图文科普 / 知识卡片 / 小红书风格
- **线条质感**：黑色软墨水手绘勾线，线条带轻微不规则感，具有手绘温度感。
- **整体质感**：插画 + 文字融合排版，图文各占约 60% 和 40%，视觉饱满但不压迫。

---

### 2. 背景与纸张质感

- **背景色**：暖米白 / 羊膏白（非纯白 `#FFFFFF`，而是接近 `#FAF6F0` 的偏暖米色）。
- **纸张纹理**：细腻手绘纸张纹理，呈现轻微的纤维与颗粒感，营造真实手账感。
- **Prompt 关键词**：`暖米白羊膏纸质感背景` / `warm off-white cream paper texture`

---

### 3. 配色方案：莫兰迪粉彩系

所有配色须采用**莫兰迪柔和粉彩色系**，避免使用纯高饱和原色（如纯红 `#FF0000`、纯蓝 `#0000FF`）。

| 色彩用途 | 色调描述 | 参考色名 |
| :--- | :--- | :--- |
| **卡片框背景色** | 浅蓝 / 浅黄 / 鼠尾草绿 / 柔粉 | 莫兰迪浅蓝、暖沙黄 |
| **胶囊标题底块** | 与卡片框同色系，略深 | 粉蓝、柔绿、奶黄 |
| **警告/对比强调** | 手绘感黄色（感叹号）/ 偏砖红（叉叉） | 暖黄、砖粉红 |
| **正向/勾勾强调** | 鼠尾草绿 / 浅薄荷绿 | 柔和草绿 |
| **金句总结框** | 手绘黄色气泡 | 明黄、香蕉黄 |
| **小智线稿** | 纯黑色墨水 | 黑色软墨 |

- **Prompt 关键词**：`莫兰迪粉彩配色` / `pastel Morandi colors` / `soft muted pastel palette`

---

### 4. 标题排版规范

| 元素 | 规范说明 | Prompt 关键词 |
| :--- | :--- | :--- |
| **顶部主标题** | 双线手绘泡泡字，居中，带彩色字填与云朵/灯泡涂鸦装饰框 | `双线手绘泡泡字大标题框` |
| **卡片胶囊小标题** | 圆角彩色胶囊底块，标有序号 `1. 2. 3.`，嵌入卡片框顶部 | `彩色胶囊小标题底块` |
| **小吊牌标注词** | 挂在绳子上的彩色手绘吊牌，用于关键词标注 | `挂在绳子上的彩色小吊牌挂签` |
| **底部金句框** | 黄色手绘气泡总结框，位于画面底部，承载核心总结金句 | `底部黄色手绘气泡金句总结框` |

---

### 5. 构图规范

- **比例**：统一采用 **3:4 竖版比例**，适配小红书主图尺寸。
- **构图**：单页全景构图，主体内容居中，底部留适量白边。
- **密度**：每张海报包含 3~4 个圆角手绘卡片框（或等效版式），视觉饱满，信息密度高。
- **Prompt 关键词**：`单页海报全景构图，中央主体居中，底部留白，3:4 比例，高清，精致细节`
